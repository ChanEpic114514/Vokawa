从分享菜单打开 Vokawa

只需在 iPhone「快捷指令」中配置一次。以后在支持系统文字分享的 App 中，选择文字 → 分享 → Translate with Vokawa。Vokawa 会填入原文，等你确认语言并点击「确认并翻译」。

这是手动创建安装教程，不是一键安装链接。

此环境无法在 Apple 设备上签名、导出或实机运行快捷指令，因此没有提供未经验证的 .shortcut 文件或虚构的 iCloud 安装链接。下面是完整的原生操作配置，不需要付费、开发者账号、第三方快捷指令工具或 API 密钥。

1. 创建分享入口

  1. 打开 iPhone 自带的 快捷指令 / Shortcuts，点 ＋ 新建，命名为 Translate with Vokawa。
  2. 打开快捷指令的 详细信息 / Details（不同 iOS 版本可能在顶部名称菜单或底部信息按钮中），开启 在共享表单中显示 / Show in Share Sheet。
  3. 顶部会出现接收输入的设置。点输入类型，清除其他类型，只开启 文本 / Text 与 富文本 / Rich text。不要选图像、文件、Safari 网页或所有类型。
  4. 将 如果没有输入 / If there is no input 设置为 询问 / Ask For → 文本 / Text。这样直接运行时可以手动粘贴；不使用自动读取剪贴板。

2. 按顺序添加操作

搜索下面的操作名称。中文名称可能因系统语言略有不同，可参照英文名称。输入栏里的变量必须通过「选择变量」插入，不能把变量名称当成普通文字输入。「计数」及「如果」之后，后面的编码操作仍须明确选择第 2 步的「合并后的文本」。

顺序操作配置
1从输入中获取文本
Get Text from Input		输入：快捷指令输入 / Shortcut Input。将富文本转为纯文本。
2合并文本
Combine Text		输入：第 1 步的文本；分隔符：新行 / New Lines。单段内容及原有换行会保留；多项文本用换行连接。
3计数
Count		输入：合并后的文本；计数单位：字符 / Characters。
4如果
If		如果「计数结果」大于 3000，在此分支中添加「显示提醒 / Show Alert」：文字过长，请选取不超过 3,000 字符的段落重新分享。；然后添加「停止此快捷指令 / Stop This Shortcut」。若系统显示「停止并输出 / Stop and Output」，设为不输出内容。否则分支不放操作；继续到「结束如果」。
5URL 编码
URL Encode		模式：编码 / Encode；输入：第 2 步的合并后的文本，不是字符计数或「如果」结果。只编码一次，且只编码文字。
6文本
Text		输入下面的网址前缀，紧接着插入第 5 步的URL 编码后的文本变量。中间没有空格或换行。
7URL输入：第 6 步完整的文本变量。不要再次编码。
8打开 URL
Open URLs		输入：第 7 步的 URL 变量。不要使用「获取 URL 内容」或直接请求 MyMemory。

第 6 步的网址前缀：

https://chanepic114514.github.io/Vokawa/#vokawa-share=

第 6 步的最终视觉形式如下；方括号表示插入的变量块，不要手打方括号或变量名字：

https://chanepic114514.github.io/Vokawa/#vokawa-share=[URL 编码后的文本]

完成后保存快捷指令。首次运行若系统询问是否允许打开 Vokawa 网站，请检查域名为 chanepic114514.github.io 后允许。建议先将 Safari 设为默认浏览器；打开 URL 的具体去向由 iOS 和默认浏览器设置决定。

3. 第一次检查

在备忘录中新建下面的两行文本，选中 → 分享 → Translate with Vokawa：

Hello + 100% & #? = 你好！
我哋聽日見 😊
  1. Vokawa 原文应包含上面两行，+、%、&、#、标点及 emoji 不应变成乱码。网址中的 #vokawa-share=… 应消失。
  2. 页面应显示「文字已接收，尚未发送」。检查原文及英／普／粤语言方向；只有点击 确认并翻译 后才请求翻译，再点击译文的播放按钮朗读。
  3. 确认前刷新：分享文字应清空且不自动发送。再次分享相同或不同文字：应重新填入，并再次等待确认。
  4. 长段落超过上限：应被快捷指令或网页拒绝，不应悄悄截断。App 最终按 UTF-16 长度限制 3,000；一个 emoji 或组合符号可能占多个单位，系统的字符计数与此可能不同。

只测试网页接收端：此链接使用公开测试文字，不会安装快捷指令，也不会自动翻译。

Safari、邮件、WhatsApp 怎么用？

Safari：长按并选中网页正文，再用选中文字的「分享」，不要只点击分享整个网页的网址。邮件：选中邮件正文后分享。App 必须实际提供系统分享入口，并传出文本。

WhatsApp 或其他 App：如果长按文字后确实有系统「分享」，可选本快捷指令；如果只有「复制／转发」，不能强制添加系统分享菜单。请复制文字 → 手动运行本快捷指令 → 在询问框中粘贴。这是明确的兼容回退，不是已经验证所有版本都能直接分享。

如果菜单里没有快捷指令，检查「在共享表单中显示」、接收类型，以及是否正在分享文字。若收到的只是网址，Vokawa 不会擅自下载网页全文。

主屏幕版与隐私

接收端支持首次打开及已打开页面的新 Fragment。iOS 是否把 HTTPS 链接交给主屏幕 PWA、Safari 现有标签或新标签，由系统决定；不能保证强制唤起已安装的 PWA，也不能保证与 Safari 共享历史和设置。可靠回退是在浏览器中继续翻译，无需另装 App。

分享文字放在 URL 的 # 后，不放在查询参数中。页面先清理分享 Fragment，再交给 React 校验；内容仅暂存在内存，不自动写入本机存储或翻译历史。确认前不会请求翻译、录音或朗读。确认后沿用现有翻译服务和历史保存设置。

Fragment 不是加密。系统、来源 App、快捷指令及浏览器在交接时仍能接触文字；页面清理不能撤销浏览器同步、扩展或系统已经记录的内容。不要把含私人内容的分享链接转发给别人。清理失败会阻止导入，并提示关闭页面。

首次使用先在线更新 Vokawa。旧 PWA 缓存可能尚无接收功能；先用 更新入口更新，再重新分享。更新过程可能清空尚未确认的分享内容，因此不应依靠它保存草稿。

验证范围

仓库提供编码、接收、超长／无效输入、重复分享、刷新和确认前网络请求的自动化测试。快捷指令配置已按动作顺序和变量依赖进行静态检查；未在 iPhone 的快捷指令 App 中搭建或运行，未验证具体 iOS／WhatsApp／邮件版本的分享界面，也未验证 PWA 自动接管链接。
