## 测试中发现并修复

- JS / Python 词典把银行职务“行長”标成行走/长度读音。已通过共享配置修正独立名词及完整“銀行行長”词语，并保留“行長路”的行走读音。
- 录音端到端测试首次只模拟 webkit 前缀接口，而浏览器提供标准接口，导致测试未调用模拟对象；已同时模拟两种接口，重新验证明确同意和停止。没有据此声称真实麦克风听写质量通过。

## 明确未验证

- 没有连接真实 iPhone / Safari / 主屏幕模式；不能声明 iOS 实机安装或离线语音通过。
- 当前 headless Chromium 实际 `speechSynthesis.getVoices()` 返回空列表。声音选择与串行回调使用模拟对象测试，真实浏览器只验证无声音时拒绝播放；**没有实际播放或听审 Apple 香港粤语声音**。
- 未做人类母语者逐字逐音节声调听审、声学基频检验或长句主观自然度评测。
- 未运行 Canto-TTS 或 Sherpa 模型；模型质量数字是上游公布数据，不是本次实测。
- 未运行真实 Qwen/Ollama 推理；假上游验证翻译协议、错误和并发行为，不证明翻译质量或 Chromebook 性能。
- 未测试真实供应商语音识别准确性。识别测试只验证授权与生命周期控制。
- GitHub Actions / Pages 尚未在远程执行；仓库连接范围内未找到 Vokawa。随代码提供工作流，但本地通过不等于远程 CI 成功。
