# Vokawa 0.6 更新与测试教程

本版完整重做翻译、对话、听读、记录、设置五个页面，加入中文 / English 操作界面，移除示例翻译模式、预填测试句子和用户界面中的调试参数。代码注释使用英文。

**这是完整项目更新，不能只上传或覆盖 `src/main.tsx`。本次不需要部署。**

## 1. 准备文件与环境

下载 `Vokawa-v0.6-complete.zip`，放入 Chromebook「Linux 文件」根目录。在终端中对应 `~`。

项目原文件夹仍为 `~/Vokawa-main`。请关闭正在运行的开发服务（在对应终端按 Ctrl+C），并保存 VS Code 中的修改。

```sh
node --version
npm --version
python3 --version
df -h ~
```

本次构建环境为 Node.js 24.19.0、npm 11.9.0。建议使用 Node.js 24 LTS；Vite 7 至少需要 Node.js 20.19 或 22.12 对应的兼容版本。

压缩包约 113 MiB，包含全部源代码和音频压缩分卷。音频展开约 133 MiB；npm 依赖还会另外占用磁盘。不要把 ZIP 原封不动地放入项目目录当作更新文件。

默认翻译和系统朗读不需要重新安装 Ollama，也不需要运行 8765 后端。

## 2. 备份你电脑上的当前版本

```sh
cd ~/Vokawa-main
vokawa_backup="../Vokawa-before-v0.6-$(date +%Y%m%d-%H%M%S).tar.gz"
tar --exclude='./node_modules' --exclude='./dist' --exclude='./.git' --exclude='./.venv' --exclude='./public/audio' -czf "$vokawa_backup" .
```

该备份保留源代码与现有音频分卷，不重复压缩依赖和展开音频。压缩包自带的 `backups/Vokawa-pre-v0.6-source.zip` 是本次使用的 GitHub 基线源代码备份，不是你电脑上的最新修改，也不包含浏览器记录。

## 3. 解压并更新项目

在 Chromebook 文件管理器中解压 `Vokawa-v0.6-complete.zip`，将里面的 `Vokawa-v0.6` 文件夹放到「Linux 文件」根目录。得到 `~/Vokawa-v0.6`。如果已有同名解压文件夹，先改名保留，再解压本次下载。

也可以使用终端：

```sh
cd ~
python3 -m zipfile -e Vokawa-v0.6-complete.zip .
```

确认是本次文件后，将内容覆盖到原项目：

```sh
cp -a ~/Vokawa-v0.6/. ~/Vokawa-main/
cd ~/Vokawa-main
npm ci
npm test
npm run build
npm run dev -- --port 5173 --strictPort
```

此操作保留原文件夹里的 `.git`。新的文件会覆盖同名旧文件，不会自动清除你自行增加的文件。旧浏览器测试文件即使残留，也不会被新配置运行；新配置只运行 `tests/product.e2e.spec.ts`。

出现本地地址后，用 Chrome 打开：

http://localhost:5173

不要双击 `index.html`，也不要在 `~` 目录直接运行 `npm ci`。npm 命令必须在包含 `package.json` 与 `package-lock.json` 的 `~/Vokawa-main` 中执行。

如果端口被占用，先在旧服务终端按 Ctrl+C，再重试。保持原来的地址和端口，有助于保留浏览器中的数据。

## 4. 建议按此顺序检查

1. 首页没有预填测试句子；能看到新的深色界面、翻译面板和咒语入口。
2. 点击右上角 `EN`：导航、按钮、设置、权限说明与错误提示切换为英文。刷新后应保持语言选择。点击「中文」可切回。
3. 输入从未用过的新句子，点击翻译；翻译过程中修改输入，应取消旧请求，不显示旧结果。
4. 点击粤语译文下方「听译文」，使用系统粤语声音。若没有可用声音，在设备系统设置下载香港粤语声音，返回应用刷新声音列表。
5. 展开「逐字听读」，测试单字录音和多音字选项。这些选项不会改变系统整句朗读；听读页面的可选语音后端会接收所选读音。
6. 收藏、复制、放大、查看记录、搜索；切换界面语言和刷新后确认记录仍在。
7. 在「对话」页完成一轮翻译，点击语言交换，让另一方输入。MyMemory 逐次翻译，不会利用前面聊天的上下文；配置自己的后端时才传入最近六轮。
8. 在「听读」页输入粤语文字，播放整句和单字。
9. 在「设置」调整速度、粤拼、自动播放与保存记录。关闭自动保存不删除旧记录，仍可手动收藏当前译文。

## 5. 咒语功能的必要说明

仓库基线没有此前对话中的咒语模块文件，因此本版重新实现了本地声学匹配，不应把旧版的实测成功率直接当成本版结果。

- 咒语文字保留为 `Konamito Kanumeya`：`ko · na · mi · to / ka · nu · me · ya`。
- 新模块使用单独的 v2 存储键。旧样本不会被删除，但需要为新模块重新录制一次。
- 首次录制：三遍咒语 → 三次正常说咒语 → 三句长度相近的其他语句 → 保存。
- 每次收录先安静一秒，然后说完整一句，最后停顿；录制与唤醒使用同一套截取方式。
- 仍采用计算阈值再加 `0.03` 的容差。如果会接受已录下的其他语句，本版会要求重新校准，而不是保存明显会误触发的配置。
- 保存成功后，再次打开同一浏览器、同一网站，无需每次重新录制。清除网站数据、换设备或更换网站地址后，需要重新设置。
- 每次聆听必须由你主动开启。唤醒后先等「请说待翻译内容」再说话。转写结果填入输入框后，点击「翻译」。
- 语音识别失败时会显示原因，并提供「重试语音输入」按钮。浏览器识别服务的 `network` 错误无法靠前端保证消除；可使用重试按钮、普通语音输入按钮或键盘输入。
- 收起咒语面板、切换页面、切换界面语言、离开网页或锁屏都会停止。它不是后台持续录音服务。

请在手机上重新做正反例测试。新算法的真实识别率未在本次环境测量。

## 6. 如果仍显示旧界面

先停止旧开发进程，再重新执行启动命令。用 Chrome 刷新页面。

若此前曾在同一地址安装 PWA，打开开发者工具 → Application → Service Workers，对 `localhost:5173` 注销旧 Worker，关闭这个地址的所有标签页，再重新打开。

**不要为此清除全部网站数据**，否则本机记录和咒语样本也可能丢失。

`localhost`、`127.0.0.1`、不同端口和 GitHub 部署网址分别有独立的本地存储；本地记录不会自动同步到手机。

## 7. 可选浏览器测试

本次交付包含八个 Playwright 场景，但生成环境没有执行真实浏览器测试。你可在本地运行：

```sh
cd ~/Vokawa-main
npm run build
npx playwright install chromium
npm run test:e2e
```

Chromium 下载会额外占用磁盘；空间紧张时可以先完成上述手动检查。浏览器测试模拟翻译和转写响应，不证明在线服务、真实发音或麦克风识别率。

## 8. 部署留到本地测试后

本次没有推送 GitHub 或部署，现有线上版本不会因本地更新而改变。

保留的 GitHub 工作流会在你之后推送 `main` 时部署。完成本地测试后，再决定是否上传。

将来部署完成，使用 iPhone Safari 打开 HTTPS 部署地址 → 分享 → 添加到主屏幕。首次使用音频需联网；即时翻译仍需要联网，主屏幕安装本身不会把在线翻译变成离线翻译。
