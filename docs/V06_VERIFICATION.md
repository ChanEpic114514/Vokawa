## 明确未验证

当前环境缺少可用的浏览器验证入口，按照环境规定未启动预览服务、未安装替代浏览器。因此未实测 CSS 渲染、布局、iPhone Safari、真实录音、系统语音音质、浏览器语音转写、在线翻译可用性或新咒语引擎的真实识别率。

Playwright 八个场景覆盖语言持久化、任意翻译、逐字控制、收藏、过期请求、network 错误、禁止自动录音、手机/桌面布局。这些场景已编写并通过测试发现，不应标为已运行通过。

保留的 Python 后端未改业务逻辑，本次没有安装其模型依赖或重新执行后端测试。默认功能不依赖该后端。

## 数据与兼容性

- 继续使用 `vokawa-v2` 保存设置和历史；界面语言单独保存。
- 旧 `demo` 偏好被设为 false，移除假定固定文段的示例翻译路径。
- Ekho 音频、词语与句子原录音、品牌图标及第三方许可保留。
- 系统整句朗读不由逐字选音控制。
- 唤醒模块是重建版本，不声称继承旧版的八次实测成绩。使用 `vokawa-wake-acoustic-v2`，需重新录制一次；旧样本不删除。
- `+0.03` 容差保留，但不能超过已录反例最小距离。样本统计不能代替真实使用准确率。
- 网络错误不会无限自动重试，用户可以主动重试转写。
- 无自动麦克风权限请求；只有点击录制/开启/重试才开始相关流程。
